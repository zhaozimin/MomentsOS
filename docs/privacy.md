# 隐私与威胁边界

MomentsOS 处理的不是普通配置，而是人的生活上下文。隐私必须由默认行为保证。

## 仓库不包含什么

公开仓库不包含：

- 作者的人设与文风样本。
- 朋友圈正文、发布历史和选择记录。
- 言壤转写、LifeOS 数据或 Obsidian 内容。
- 数据库、运行日志、完整提示词或模型输出。
- 主机名、用户绝对路径、访问令牌或 API 密钥。
- 私有生产系统的调度、通知和部署配置。

## 数据存在哪里

默认全部运行数据位于 `~/.momentsos/`。其中 `runs/` 的风险最高，因为它包含模型调用前的完整上下文。

请使用磁盘加密，并把备份视为同等敏感的数据。不要把运行目录放进 Git、同步到公共网盘或附在问题报告里。

## 数据什么时候离开电脑

- `manual`：程序不会发送数据。你手动粘贴时，数据进入你选择的产品。
- 本地兼容接口：目标是 `127.0.0.1`、`localhost` 或 `::1` 时，请求留在本机。
- 远程兼容接口：完整提示词会发送给远程服务。程序要求显式设置 `allow_cloud_context=true`。

该开关只证明你做过选择，不代表远程服务安全。你仍需核对服务商的保留、训练、地域和删除政策。

## 外部来源

言壤 Markdown、LifeOS 和其他 Markdown 来源全部只读。LifeOS 非本机地址默认拒绝，除非该来源显式设置 `allow_remote=true`。

目录来源会按通配符读取文件。过宽的目录是最常见风险。只接入为 MomentsOS 单独准备的目录。

## 发布前检查

```bash
python3 scripts/privacy_check.py
git status --short
git diff --cached
```

扫描器检查常见密钥、用户绝对路径和运行数据库。它发现不了所有私人事实。最终提交必须人工逐文件检查。

## 报告问题

安全漏洞请使用 GitHub 的私密安全报告功能。不要在公开 Issue 中粘贴密钥、提示词、运行目录或真实上下文。
